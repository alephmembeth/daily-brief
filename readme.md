# Daily Brief

<img src="daily_brief_example.jpg" align="right" width="240"/>

This Python script generates a daily brief image designed for 80mm thermal receipt printers and sends it to the print queue.[^1] It fetches weather data to plot a temperature line graph and rain probability bar chart, extracts events from iCal URLs, tasks from Things via AppleScript, and vocabulary from Obsidian. Additionally, it fetches the latest headlines from Tagesschau and a random trivia fact.

[^1]: Inspired by a [Reddit post](https://www.reddit.com/r/aiagents/comments/1taiina/i_made_an_agentic_daily_brief_for_my_kids_with_a/).
