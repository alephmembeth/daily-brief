# Daily Brief

<img src="daily_brief_example.jpg" align="right" width="240"/>

This Python script generates a daily brief image designed for 80mm thermal receipt printers and sends it to the print queue. It fetches weather data to plot a temperature line graph and rain probability bar chart, extracts events from iCal URLs and tasks from Things via AppleScript. Additionally, it fetches the latest headlines from Tagesschau and a random trivia fact.
